# 必应轻壁纸 1.1.5

Windows 10 / 11（64 位）的必应每日壁纸工具。支持同步桌面与锁屏、自定义更新时间、登录自启、托盘操作和旧图清理。

## 安装

下载下方的 `BingWallpaperLite-Setup-1.1.5.exe` 并运行。无需管理员权限，已有版本可以直接覆盖安装，配置会保留。文件校验值见同名 `.sha256` 附件。

## 本版改动

- 合并设置和更新程序，程序文件由三个减为两个。
- 托盘文件缩小到约 57 KiB，辅助程序约 82 KiB。
- 优化预览缓存、状态查询和重绘。
- 修复下拉菜单关闭异常、界面残影和托盘加载输入法模块的问题。
- 安装、卸载只管理本工具，不修改原版必应壁纸。

本机空闲实测：托盘私有工作集约 1 MiB，含共享系统 DLL 的总工作集约 11 MiB。设置窗口和图片更新会有额外占用。

安装包尚未进行代码签名。若遇到运行异常或安全软件拦截，请在 Issue 中提供 Windows 版本、复现步骤及相关日志或检测信息。
