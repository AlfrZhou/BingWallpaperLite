# 必应轻壁纸

每天换一张必应壁纸，同时设置桌面和锁屏。

适用于 Windows 10 / 11（64 位）。原生托盘常驻，设置窗口和更新模块按需运行。

## 下载与安装

在 [Releases](https://github.com/AlfrZhou/BingWallpaperLite/releases/latest) 下载 `BingWallpaperLite-Setup-1.1.6.exe`，双击安装。已有版本直接覆盖安装即可，配置会保留。

- 无需管理员权限。
- 可选择登录后启动、创建桌面快捷方式。
- 可从 Windows“已安装的应用”或开始菜单卸载。
- 安装和卸载只管理本工具，不改动原版必应壁纸的进程、自启或计划任务。

安装包附带 `.sha256` 校验文件。当前版本尚未进行代码签名；如果遇到安全软件拦截，请在 [Issue](https://github.com/AlfrZhou/BingWallpaperLite/issues/new/choose) 中附上检测名称和文件 SHA-256，便于核查。

## 功能

- 获取指定地区的必应每日图片，支持 UHD 等分辨率。
- 同步设置桌面和锁屏。
- 按指定时间更新，启动时检查，休眠恢复后补做错过的更新。
- 更新失败后每 15 分钟重试。
- 按保留张数清理旧图。只有桌面和锁屏都设置成功后才清理，失败时保留已有图片。
- 提供托盘菜单、图片目录和运行日志入口。

图片清理仅限本工具生成的文件，不递归，也不处理其他目录中的图片。

## 使用

双击托盘图标打开设置。调整选项后点击“保存”；点击“立即更新”手动同步。

关闭或最小化设置窗口后，界面进程会退出，托盘继续运行。彻底退出请使用托盘右键菜单中的“退出”。

| 默认设置 | 值 |
| --- | --- |
| 地区 | 中国（zh-CN） |
| 分辨率 | UHD |
| 更新时间 | 每天 08:05，按电脑本地时间 |
| 保留图片 | 1 张 |

## 资源占用

程序由两个文件组成：

| 文件 | 用途 | 大小 |
| --- | --- | --- |
| `BingWallpaperLite.exe` | 原生托盘与定时调度 | 约 57 KiB |
| `BingWallpaperHelper.exe` | 设置窗口或图片更新，结束后退出 | 约 85 KiB |

本机空闲实测：托盘私有工作集约 **1 MiB**，私有内存约 **1.8 MiB**；包含共享系统 DLL 的总工作集约 **11 MiB**。打开设置、下载图片或设置壁纸时会产生额外占用，数值也会随系统环境变化。

不使用定时清空工作集压低数字，没有额外服务或后台计划任务。

## 文件位置

| 内容 | 默认位置 |
| --- | --- |
| 程序 | `%LOCALAPPDATA%\Programs\BingWallpaperLite` |
| 图片、配置、状态与日志 | `%LOCALAPPDATA%\BingWallpaperLite` |

`config.json` 保存设置，`state.json` 记录同步状态，`update.log` 记录更新结果。卸载保留图片和配置，当前壁纸不会因卸载而被删除。
